# Research provenance

[`deep-research-report.md`](deep-research-report.md) is user-supplied Deep Research input copied into this repository without rewriting. It is design context, not runtime authority.

The report contains claims tied to its stated research snapshot date. Product versions, model names, interfaces, availability, and recommendations may therefore become stale. It also retains ChatGPT citation markers that may not resolve when rendered on GitHub. Runtime behavior is governed by the source code, schemas, configuration, tests, and current operator-approved policy in this repository.
